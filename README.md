# แดชบอร์ดวาระคงเหลือ (Days-Left Dashboard)

แดชบอร์ดเว็บสำหรับติดตาม **วาระคงเหลือ** (Days Left) ของเจ้าหน้าที่ประจำพื้นที่
(ผู้ใหญ่บ้าน / กำนัน / ผู้ช่วยฯ) โดยคำนวณวันคงเหลือ **แบบเรียลไทม์จากเวลาปัจจุบัน**
จาก **วันที่สิ้นสุดวาระ** ที่ได้จากข้อมูลต้นทาง — ไม่ใช้ค่าคงที่ใด ๆ

- โซนเวลา: **Asia/Bangkok (UTC+7)**
- ภาษา UI: ไทย (แสดงปี พ.ศ.)
- ไม่มี dependency ภายนอก (ใช้ Node.js มาตรฐาน + เบราว์เซอร์เท่านั้น)

---

## เริ่มต้นใช้งาน

```bash
npm start          # รันเซิร์ฟเวอร์ แล้วเปิด http://localhost:4173
npm test           # รันเทสต์ทั้งหมด (node --test)
npm run convert:csv  # แปลง CSV ต้นฉบับ (TIS-620) → data/vara_utf8.csv (UTF-8)
```

ข้อกำหนด: Node.js ≥ 18 (ทดสอบกับ Node 26 แล้ว)

---

## วิธีคิด "วันคงเหลือ"

1. **แหล่งความจริงคือวันที่สิ้นสุดวาระ** (`endDate`) — ไม่ใช่ค่าที่อยู่ในไฟล์โดยตรง
2. ชุดข้อมูล `วาระ ผญบ - วาระ.csv` มีคอลัมน์ **"วาระคงเหลือ"** เป็น *ระยะเวลาที่เหลือ*
   เช่น `5 ปี 1 เดือน`, `0 ปี 2 เดือน` (วัด ณ **วันที่อ้างอิงข้อมูล**)
3. แปลงเป็นวันที่สิ้นสุดก่อน:
   ```
   วันที่สิ้นสุดวาระ = วันที่อ้างอิงข้อมูล + ระยะเวลาวาระคงเหลือ
   ```
   - วันที่อ้างอิงตั้งค่าได้ที่ `js/config.js` → `dataReferenceDate` (ค่าเริ่มต้นคือวันที่แก้ไขไฟล์ต้นฉบับ `2026-08-13`)
   - หรือปรับได้จากหน้าเว็บ: ปุ่ม **⚙ ตั้งค่า** (บันทึกใน localStorage)
4. คำนวณสดทุกครั้ง:
   ```
   วันคงเหลือ = วันที่สิ้นสุดวาระ − วันนี้ (โซนเวลา Asia/Bangkok)
   ```
5. คำนวณใหม่ให้อัตโนมัติเมื่อ **วันที่เปลี่ยน (เที่ยงคืนตามเวลาไทย)**, เมื่อกลับมาเปิดแท็บ, และเมื่อกด **↻ รีเฟรช**

การคำนวณวันใช้ `Date.UTC` สำหรับวันที่แบบ "วันเดียวเท่านั้น" (calendar-accurate)
จึงไม่มีความผิดเพี้ยนจาก timezone หรือ DST

## สถานะ (Status)

| สถานะ | เงื่อนไข | สี |
|---|---|---|
| ดำรงวาระ (Active) | วันคงเหลือ > เกณฑ์ | เขียว |
| ใกล้หมดวาระ (Expiring Soon) | 0 ≤ วันคงเหลือ ≤ เกณฑ์ (รวมถึง "หมดวาระวันนี้") | เหลือง |
| หมดวาระแล้ว (Expired) | วันคงเหลือ < 0 | แดง |
| ข้อมูลไม่สมบูรณ์ (Invalid) | วาระ/วันที่ไม่ถูกต้องหรือขาดหาย | เทา |

- **เกณฑ์ "ใกล้หมดวาระ"** ตั้งค่าได้ (ค่าเริ่มต้น **30 วัน**) — ที่ `js/config.js`
  หรือหน้าเว็บ **⚙ ตั้งค่า**
- สิ้นสุดวาระพอดีวันนี้ (`วันคงเหลือ = 0`) นับเป็น "ใกล้หมดวาระ" (ยังไม่ถือว่าหมดวาระ)
- ข้อมูลไม่สมบูรณ์จะ **ไม่ถูกนับ** ใน Active / Expiring / Expired แต่แสดงป้าย ⚠ และเหตุผล
  (เช่น `ไม่มีข้อมูลวาระคงเหลือ`, `รูปแบบวาระคงเหลือไม่ถูกต้อง: "…"`)

## รูปแบบการแสดงวันคงเหลือ

- ตัวเลข **วันคงเหลือ** แสดงเป็นจำนวนเต็มเสมอ (ใช้เรียง/กรองได้)
- ข้อความมนุษย์อ่านง่าย (ภาษาไทย): `เหลือ 5 ปี 1 เดือน`, `เหลือ 3 เดือน 12 วัน`,
  `เหลือ 125 วัน`, `หมดวาระวันนี้`, `หมดวาระแล้ว`

---

## ข้อมูลและความสมบูรณ์ของข้อมูล

- **ไฟล์ต้นฉบับไม่ถูกแก้ไข** — แดชบอร์ดอ่านจากสำเนา UTF-8 ที่ `data/vara_utf8.csv`
  (แปลงจาก TIS-620 ด้วย `npm run convert:csv`; ต้นฉบับคือ `วาระ ผญบ - วาระ.csv`)
- คอลัมน์ "วันที่เริ่มวาระ" **ไม่มีอยู่ในชุดข้อมูลต้นทาง** จึงแสดง "—" อย่างตรงไปตรงมา
  (ไม่มีการคาดเดา) — ช่องนี้จะแสดงวันที่จริงเมื่อชุดข้อมูลมีคอลัมน์นั้น
- ถ้าวาระคงเหลือว่าง/รูปแบบผิด จะถูก flag เป็น "ข้อมูลไม่สมบูรณ์" พร้อมเหตุผล

---

## การจัดการวันที่และรูปแบบไทย

- `parseDurationWara` — แปลง `5 ปี 1 เดือน`, `0 ปี 2 เดือน`, `3 เดือน`, `5 วัน`, เลขไทย (๑-๙)
- `parseDate` — รองรับ ISO `2026-08-13`, ไทย ว/ด/ป `13/8/2569`, ชื่อเดือนไทย `13 ส.ค. 2569`,
  ปี พ.ศ. แปลงเป็น ค.ศ. อัตโนมัติ (ปี ≥ 2400)
- **ไม่สมมติว่าเป็น MM/DD/YYYY** — `08/13/2026` ถูกปฏิเสธ (เดือน 13 ไม่มี) ตามรูปแบบไทย ว/ด/ป
- ทุกวันที่จะถูก normalize เป็น `{ y, m, d }` ก่อนคำนวณ

## เทสต์

```bash
npm test
```

ครอบคลุม (32 เทสต์):

- วาระปกติ (Active), ใกล้หมดวาระ, หมดวาระแล้ว, สิ้นสุดวาระพอดีวันนี้ (0 วัน)
- วันที่ขาดหาย / รูปแบบวาระผิด → ข้อมูลไม่สมบูรณ์
- รูปแบบวันที่ไทย (พ.ศ., ชื่อเดือน, เลขไทย) และการไม่สมมติ MM/DD/YYYY
- โซนเวลา Asia/Bangkok (แปลง UTC → เวลาไทย, วันเปลี่ยนข้ามเขต)
- วันคงเหลือลดลงเมื่อ `now` เปลี่ยนไป (ไม่อยู่นิ่ง)
- CSV parser (RFC 4180: เครื่องหมายคำพูด, บรรทัดใหม่ในฟิลด์, CRLF, BOM)
- บูรณาการกับชุดข้อมูลจริง: 181 รายการ คำนวณครบ ไม่มีข้อมูลไม่สมบูรณ์

## โครงสร้างโปรเจกต์

```
index.html            หน้าแดชบอร์ด
css/styles.css        สไตล์
js/config.js          การตั้งค่า (โซนเวลา, วันที่อ้างอิง, เกณฑ์, สี)
js/csv.js             CSV parser (RFC 4180)
js/dates.js           วันที่/เวลา: พาร์สไทย, บางกอก-นา, คณิตปฏิทิน, รูปแบบไทย
js/model.js           สร้าง record, สถานะ, KPI, ค้นหา/กรอง/เรียง
js/dashboard.js       UI logic (เรนเดอร์, ตั้งค่า, รีเฟรชเที่ยงคืน)
data/vara_utf8.csv    สำเนาข้อมูล UTF-8 (ไฟล์ต้นฉบับไม่ถูกแก้ไข)
scripts/convert-csv.mjs  แปลง TIS-620 → UTF-8 (ทำซ้ำได้)
server.js             เซิร์ฟเวอร์ไฟล์สถิต (ไม่มี dependency)
tests/                เทสต์ (node --test)
```

โมดูลใน `js/` เป็น ES Modules แบบบริสุทธิ์ (ไม่มี dependency) จึงใช้ร่วมกันได้ทั้ง
ในเบราว์เซอร์และ Node (สำหรับเทสต์)

## หมายเหตุการใช้งานจริง

- ค่าเริ่มต้นของ `dataReferenceDate` ใช้วันที่แก้ไขไฟล์ต้นฉบับ (13 ส.ค. 2569)
  หากหน่วยงานทราบวันที่ที่วัดค่า "วาระคงเหลือ" จริง ควรแก้ที่ `js/config.js`
  (หรือผ่าน "⚙ ตั้งค่า") เพื่อให้วันที่สิ้นสุดวาระแม่นยำ — แดชบอร์ดแสดงวันที่อ้างอิง
  ให้เห็นเสมอในส่วน "วิธีอ่านแดชบอร์ด"
- การ deploy: นำไฟล์ทั้งโปรเจกต์ไปไว้บนเว็บเซิร์ฟเวอร์สถิตใดก็ได้ (หรือรัน `npm start`)
