การตั้งค่า

วันที่สิ้นสุดวาระ = วันที่อ้างอิง + วาระคงเหลือ (เช่น "5 ปี 1 เดือน") ค่าที่แก้จะถูกบันทึกในเบราว์เซอร์นี้ และมีผลเหนือค่าที่กำหนดใน js/config.js โดยไม่แก้ไฟล์ข้อมูลต้นฉบับ

การแจ้งเตือนวาระ (อีเมล)

แจ้งเตือนอัตโนมัติ 6 เดือน / 1 เดือน / สรุปประจำปี — อัปเดตทุกนาที

รายชื่อและวันคงเหลือ

ลำดับ ชื่อ ตำแหน่ง พื้นที่ วันที่เริ่มวาระ วันที่สิ้นสุดวาระ วาระคงเหลือ (ข้อมูลเดิม) วันคงเหลือ สถานะ หมายเหตุ

วิธีอ่านแดชบอร์ด

  • ดำรงวาระ — วันคงเหลือ > เกณฑ์ ใกล้หมดวาระ — 0 ≤ วันคงเหลือ ≤ เกณฑ์ (รวมถึงวันสิ้นสุดพอดี เรียกว่า "หมดวาระวันนี้") หมดวาระแล้ว — วันคงเหลือ < 0 ข้อมูลไม่สมบูรณ์ — วาระหรือวันที่ไม่ถูกต้อง/ขาดหาย
  • วันคงเหลือ คำนวณสดทุกครั้งจากเวลาปัจจุบัน: วันคงเหลือ = วันที่สิ้นสุดวาระ − วันนี้ (โซนเวลา Asia/Bangkok) และคำนวณใหม่ให้อัตโนมัติเมื่อวันที่เปลี่ยน (เที่ยงคืนตามเวลาไทย)
  • วันที่สิ้นสุดวาระ ได้จากข้อมูล "วาระคงเหลือ" (เช่น "5 ปี 1 เดือน") บวกกับ วันที่อ้างอิงข้อมูล — แก้ได้ใน "ตั้งค่า"
  • ข้อมูลอ้างอิง ณ วันที่ — • เกณฑ์ใกล้หมดวาระ ≤ — วัน • อัปเดตล่าสุด — น. • จำนวน — ราย

แหล่งข้อมูล: ไฟล์ "วาระ ผญบ - วาระ.csv" (ต้นฉบับไม่ถูกแก้ไข — แดชบอร์ดอ่านจากสำเนา UTF-8 ที่ data/vara_utf8.csv)
